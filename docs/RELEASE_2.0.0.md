# BWOS 2.0.0

The rebuilt BWOS shell is now the default application. `build.ps1`, the portable `BWOS.exe`, the existing startup entry and installation path use the new core. The original data directory, browser profile, sign-ins, preferences and phone-pairing endpoint remain in place during an in-place update. The local shell and LAN ports remain 47913 and 47914.

The replacement introduces explicit ownership of provider playback and temporary collection tabs, separate navigation/playback action lanes, bounded acknowledgements, cancellation and duplicate protection. Home selects the retained fullscreen shell before asking a provider for a snapshot. Collector cleanup cannot promote or remove an owned playback session. YouTube destinations share the TV route, and Netflix/Prime title launches retain the native playback intent.

The new Home, For You, Games, Apps, Devices and Settings screens include spatial focus, provider logo filters, progressive artwork, deduplicated/paged shelves, Unicode search and keyboard, manual games, a compact stable Now Playing cloud and controller mappings. The Windows game/controller/device/voice adapters, persistent phone pairing, DIAL/AirPlay support and selected-screen WebRTC sender remain integrated. Phone and viewer actions carry request identities and wait for bounded completion; Home has a separate phone queue.

Validation: 21 primary host assertions, 16 core/session tests, isolated headless UI checks, and the existing 207 host assertions plus 13 JavaScript test files passed before promotion. The promoted default host reported 2.0.0, a connected adapter and an acknowledged Home action. Hash checks retained preferences, phone records, session key, video/recommendation caches and watch history. These are host/adapter checks, not physical controller or audio verification. Generated UI/capture fixtures are not signed-in provider or device evidence.

Material limits: the direct YouTube TV route is a compatibility integration; provider-controlled DRM, background playback, captions and progression are not guaranteed. The last live Windows inspection was stopped because Computer Use could not confidently identify Edge's URL. Actual audio continuity, physical controller Home, fresh signed-in feeds, real Hindi/Indian-English microphone behavior with music interference and Mac/Safari screen/audio reception remain unverified. Wake detection still uses the existing Whisper loop; a separately verified fast wake detector is not implemented. Protected screen capture can be black, and system audio requires an actual returned audio track.

For an in-place upgrade, close BWOS, replace only `BWOS.exe`, `ui` and `extensions`, and retain `data`. `install.ps1` preserves data and backs up the previous app payload. The former 1.8.1 source and fixes remain in the repository and can be built separately with `build.ps1 -Legacy`; this does not change the default build. No personal data, tokens, profiles, voice models or generated browser caches are included in the release ZIP.
